# Job Tracker (Spreadsheet + Auto Reminders)

- `Job-Tracker.xlsx` - Dashboard, Jobs tracker (500 rows), Settings, Reminder Log, How To Use.
- `Code.gs` - Google Apps Script: daily email reminders, Add Job form, auto-fill "Added By"/"Date Added".

## Setup (3 minutes)
1. Upload `Job-Tracker.xlsx` to Google Drive, open it, then File > Save as Google Sheets.
2. Extensions > Apps Script > paste all of `Code.gs` > Save.
3. In the Settings sheet, put your email in C4.
4. Reload the sheet > menu **Job Tracker > Turn On Daily Auto-Reminders** > allow permissions.
5. Test: **Job Tracker > Send Reminders Now**.

Delete the 5 SAMPLE rows on the Jobs sheet before real use.
